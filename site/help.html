Questions

Fair questions

Is it really free?

Yes. Cadence is open source under the MIT license, with no account, trial or word limit.

Does anything I say leave my Mac?

No. Transcription runs on your Mac, and Cadence has no networking code. History is encrypted on your disk, and audio is only kept if you turn that on.

Which languages?

Any language the bundled Whisper model handles, two at a time: one per Option key, or set either key to detect the language automatically. English and Spanish are tested the most.

Is the Terminal line safe?

It runs a short script you can read first. It only downloads the release from GitHub, stops if the file doesn't match the published checksum, and copies Cadence.app into Applications. No admin password, and it never touches your history in ~/.cadence.

Why does macOS warn me when I first open it?

It isn't notarized, because that costs $99 a year and Cadence is free. The one-line install avoids the warning entirely. If you used the .dmg, here's how to open it on any macOS version, and how to check the file is genuine.

Intel Mac? Windows? iPhone?

Not yet. Cadence is built for Apple silicon Macs only, so it won't open on an Intel Mac. Windows is planned.

Is it affiliated with Wispr Flow, Superwhisper, Apple or OpenAI?

No. They're named only to compare and to credit. Cadence is an independent project.

Troubleshooting

If something isn't working

macOS says Cadence can't be opened

That's the one-time notice for apps Apple hasn't notarized. Follow the first-open steps, or reinstall with the one-line install, which avoids it.

Holding Option does nothing

Cadence needs Accessibility to hear the key and type for you. Open System Settings › Privacy & Security › Accessibility. If Cadence is listed but it still doesn't work, remove it with the minus button, add it again from Applications, then quit and reopen Cadence.

The pill appears but no text comes out

Check System Settings › Privacy & Security › Microphone and make sure Cadence is on. The Cadence menu's Dictation Settings shows which microphone it is actually using.

It picks up music or people around me

Cadence listens through your Mac's microphone, so loud rooms and nearby voices can get into a dictation. With earbuds in, Cadence uses their microphone, which sits closest to your mouth. Without them, keep the Mac close and speak a little louder than the room. If other people are talking nearby, turn on Noisy Room Mode in Dictation Settings: it makes fewer mistakes, but results take longer. Dictation Settings also shows which microphone is in use.

Spanish (or my second language) comes out wrong

Make sure you're holding the Option key bound to that language (Left Option by default) and that the language is set in the Cadence menu. A short pause before you start speaking helps it lock on.

How do I start over?

Quit Cadence, delete it from Applications, and install it again with the one-line command. Your history in ~/.cadence is kept unless you delete that folder.
