Get Cadence

Free for Apple silicon Macs on macOS 14 Sonoma or later. The one-line install is the easiest: no security warning and no admin password.

Install

Latest: Cadence 0.1.6, released November 2, 2026. What’s new

Install with one line

Open Terminal (press ⌘ Space, type Terminal, press Return), paste this and press Return:

curl -fsSL https://cadence-dictation.pages.dev/install.sh | sh

It downloads Cadence, checks it's the genuine file, puts it in Applications and opens it. No security warning, no admin password. Run the same line again to update. Read the script first, it's short.

Apple silicon Mac · macOS 14 Sonoma or later · about 500 MB, because the speech model comes with it

or

Download Cadence.dmg

Or with Homebrew. No admin password and no security warning either; it installs into your own Applications folder:

brew tap danielcuesta007/cadence https://github.com/danielcuesta007/cadence
brew install --cask --appdir=~/Applications cadence

Used the .dmg? Why macOS asks you to confirm

The one-line install and Homebrew skip all of this: each checks the file against its published checksum, then clears the flag macOS puts on downloaded apps. If you downloaded the .dmg in a browser instead, read on. (Dragging into Applications may ask for an administrator's password; without one, drag Cadence into the Applications folder inside your home folder.)

Apple only skips that warning for apps from developers who pay $99 a year for its Developer Program. Cadence is free, and staying free meant not passing that cost on to you. So it isn't notarized by Apple, and macOS will ask you to confirm once, the first time you open it. That was a deliberate choice, not an oversight.

Open it the first time

  1. Drag Cadence onto Applications, then eject the Cadence disk. Open Cadence from Applications, not from the disk image.
  2. macOS says it can't check or verify the app. Click Done (or OK). Nothing is wrong with the file; this is the one-time notice for apps Apple hasn't notarized.
  3. Open System Settings › Privacy & Security and scroll down to Security. Next to "Cadence was blocked", click Open Anyway, then confirm with your password or Touch ID.

On macOS 14 Sonoma there's a shortcut: Control-click Cadence in Applications, choose Open, then click Open again.

After that it opens normally. Cadence then asks for two permissions: Microphone to hear you and Accessibility to type into other apps.

No Open Anyway button?

It only shows for about an hour after macOS blocks the app, so open Cadence once more and look again. If it still isn't there, paste this into Terminal, press Return, then open Cadence normally:

xattr -dr com.apple.quarantine /Applications/Cadence.app

If Cadence is in the Applications folder inside your home folder, use ~/Applications/Cadence.app instead. That removes the "downloaded from the internet" flag macOS puts on the app, and changes nothing else. Only run it on a download whose checksum matches the one below.

Cadence needs an Apple silicon Mac (M1 or newer) on macOS 14 Sonoma or later. On an older Mac it won't open, even after these steps.

Want a desktop widget?

It comes with the app. Open the Cadence menu in your Mac’s menu bar and turn on Show Desktop Widget to see today’s and this week’s words, streak, pace, time saved and all-time words. Click the widget’s logo to open Cadence. Drag it to place it; hide it anytime from the same menu or its close button. It stays on your desktop while Cadence is running, and remembers your choice next time.

Check it's the real file

Every release publishes its SHA-256 checksum. In Terminal, run shasum -a 256 ~/Downloads/Cadence.dmg and compare the result with:

7e1933c358aa05451e77b2749e5bb96cc34d8ddd0aa4232c83580ff5546d16d3

You can also read every line of the source on GitHub, or build it yourself from there.

Keep it current

Update, go back, or remove it.

Update

Run the same install line again. It replaces Cadence in place, keeps your history and settings, and checks the new file's checksum first. With Homebrew: brew upgrade --cask cadence.

Which version do I have?

Open the Cadence menu in the menu bar: the version is at the top. Every version and what changed is on the version history.

Go back a version

Each version's release page has its own Cadence.dmg and checksum. Quit Cadence, then install the older one over it. Your history stays put.

Remove it

Quit Cadence from its menu, then drag it from Applications to the Trash (or brew uninstall --cask cadence). Your history stays in ~/.cadence until you delete that folder yourself.
